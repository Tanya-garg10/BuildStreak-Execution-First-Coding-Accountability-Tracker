# BuildStreak 🔥
### Execution-First Coding Accountability Tracker

BuildStreak is a high-performance productivity suite designed for developers who want to stay consistent, track their builds, and gamify their coding journey. Built for hackathons and daily execution.

## 🚀 Key Features

### 🏆 Gamified Progress
- **Level System**: Advance from *Novice* to *Master Builder* based on your consistency.
- **Achievements & Badges**: Unlock medals like **Night Owl**, **3-Day Warrior**, and **GitHub Linker**.
- **Streak Tracking**: Keep the flame alive with daily logs.

### 📊 Advanced Analytics
- **GitHub-style Heatmap**: Visualize your activity over the last year.
- **Deep Insights**: Track **Longest Streak**, **Weekly Consistency %**, and your **Power Score**.
- **Build History**: A full, searchable timeline of every feature you've shipped.

### ⏱️ Productivity Tools
- **Focus Timer**: Built-in 25-minute Pomodoro timer to keep you in the zone.
- **GitHub Integration**: Attach repository links directly to your daily builds.
- **Smart Reminders**: Dashboard banners to ensure you never break your streak.

### 🎨 Personalization
- **Theme Accents**: Choose your vibe with **Blue, Purple, or Green** theme colors.
- **Custom Profile**: Set your display name for a personalized experience.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS v4, Framer Motion (Animations)
- **Icons**: Lucide React
- **State**: Persistent LocalStorage (Zero backend required for local use)
- **Date Handling**: date-fns

## 🏁 Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/Tanya-garg10/BuildStreak-Execution-First-Coding-Accountability-Tracker.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
